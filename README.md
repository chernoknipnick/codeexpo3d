# CodeExpo 3D

Отдельный браузерный прототип учебной выставки программирования, вдохновлённый проектом AgroExpo3D. Исходный AgroExpo3D не изменяется.

Шесть стендов: Java, SQL, Web, Python, Git, тестирование. У каждого — учебное объяснение и короткий вопрос. За первое правильное решение начисляется 100 XP, максимум — 600 XP. Задания можно повторять без повторного начисления.

## Запуск

```sh
python -m http.server 8766 --directory dist
```

Открыть http://localhost:8766. Установка зависимостей и сборка не нужны. Three.js r152 находится локально в `dist/vendor/`.

## Управление

- WASD или стрелки — движение; Shift — быстрее.
- Перетаскивание — поворот камеры; колёсико — масштаб.
- E — открыть ближайший стенд; можно также нажать на его экран.
- M — список стендов и быстрый переход; H — помощь; Esc — закрыть окно.
- На телефоне — экранные стрелки и кнопка взаимодействия.

## Структура

- `dist/content.js` — тексты, вопросы и ответы стендов.
- `dist/app.js` — 3D-павильон, персонаж, управление, проверка ответов.
- `dist/index.html`, `style.css` — интерфейс.
- `.github/workflows/pages.yml` — публикация `dist` на GitHub Pages после push в main.

Имя и прогресс сохраняются только в браузере. Нет регистрации, сбора персональных данных, совместной игры или учительского кабинета. Код из заданий показан для разбора, произвольный код не исполняется. Java и SQL связаны с существующим интерактивным учебником. Эта версия предназначена для пробного занятия; перенос в Roblox пока не выполнялся.
